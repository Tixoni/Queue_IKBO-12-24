# Бот очереди к практическим работам

Python 3.11+, aiogram 3, SQLite. Бот работает long polling на вашем ПК. SQLite WAL, `busy_timeout`, `BEGIN IMMEDIATE` и уникальность `(очередь, Telegram user_id)` предотвращают дубли и гонки между одновременными нажатиями, пока работает один экземпляр бота на одном компьютере.

## Запуск

1. Установите Python 3.11+.
2. В отдельном PowerShell: `py -m venv .venv`, затем `.venv\Scripts\Activate.ps1`.
3. `pip install -r requirements.txt`.
4. Создайте `secrets/.env` по образцу в `secrets/README.md`.
5. Запустите бота командой `py main.py`.

Секреты (токен Telegram и список ID администраторов) хранятся в `secrets/.env`, папка исключена из Git. Секреты API расписания не нужны. Расписание обновляется при старте и каждые 6 часов, кэшируются данные на 14 дней.

При сетевой ошибке `schedule-of.mirea.ru` проверьте подключение к интернету и доступ к домену университета. При сетевой ошибке `api.telegram.org` проверьте доступ Telegram Bot API из вашей сети; бот автоматически повторяет попытки подключения.

## Структура кода

- `main.py` — сборка: БД, клиент расписания, диспетчер, polling.
- `src/bot/handlers.py` — обработчики команд, кнопок и диалогов (aiogram `Router`).
- `src/bot/screens.py` — сборка текста и клавиатуры экранов.
- `src/bot/keyboards.py`, `src/bot/formatting.py` — клавиатуры и форматирование (`Lesson` — разобранная пара).
- `src/sync.py` — обновление расписания (по кнопке и каждые 6 часов).
- `src/db.py` — SQLite (схема не менялась), `src/schedule.py` — загрузка расписания МИРЭА.

## Возможности

- Главное меню с кнопками «Записаться», «Мои записи», «Указать имя» и кнопкой администрирования для админов.
- Запись начинается с актуального расписания: выбор дня → пара с временем, преподавателем и аудиторией → открытая очередь.
- Карточка своей записи показывает соответствующую пару из расписания.
- Очередь автоматически создаётся для пары из расписания и доступна без ручного разрешения.
- Любой участник может создать в очереди список занятых тем: выбрать пару, указать название списка и отправить темы по одной на строке.
- Запись в очередь и выход из неё без ручного ввода ID.
- Администраторская команда `/admin_add_user ID_очереди TELEGRAM_ID Имя` позволяет вручную добавить студента.
- Команда `/queue` показывает ваши записи.

Очередь использует Telegram-имя, пока пользователь не задаст отображаемое имя кнопкой «Указать имя».

При первом открытии пары бот создаёт для неё постоянную очередь. Списки тем привязаны к выбранной паре и дате; название и сами темы указывает создатель списка. ID очереди показывается администраторам для ручного добавления студентов.

Расписание загружается напрямую с открытых маршрутов `schedule-of.mirea.ru`: поиск группы и iCalendar выгрузка. Локальный API-сервис для этого не нужен. При первом запуске обновление делается автоматически; кнопку «Обновить расписание» можно нажать для повторной загрузки. Основано на описании открытых маршрутов в [реализации коннектора](https://github.com/Wyndace/rtu-mirea-schedule-api/blob/main/src/app/connectors/schedule.py); это сторонний проект, не официальная документация университета.
